# Education Quizzes

Адаптивные учебные самопроверки на React, TypeScript и shadcn/ui. Статический сайт публикуется через GitHub Pages; тесты и попытки хранятся в Cloud Firestore проекта `education-9d7c6` на бесплатном тарифе Spark.

## Доступ

- Ученик открывает назначение по отдельной длинной непредсказуемой ссылке без аккаунта и экрана входа.
- У ученик есть личная ссылка `#/my/…` с тестами по предметам, прогрессом и архивом без баллов. Взрослый получает отдельную ссылку `#/review/…`: она показывает активные тесты и новые непросмотренные результаты сверху. Просмотр списков не меняет ответы; родитель может пометить результат просмотренным и скопировать инструкцию агенту для связанного теста. Административный кабинет `#/dashboard/…` остаётся отдельным.
- Ссылки выдаются на конкретную область доступа. Firestore запрещает перебор коллекций и разрешает доступ только к документу по известному случайному идентификатору. Ссылки можно отозвать удалением соответствующих документов.
- Браузер работает с Firestore через веб-SDK. Код создания тестов и проверки открытых ответов работает локально через административный SDK и учётные данные владельца, которые не попадают в GitHub.

Google Authentication не используется. Случайный идентификатор в ссылке служит ключом доступа: любой, кому передали ссылку, получает соответствующие ей права.

## Поведение

- Одна назначенная ссылка допускает одну отправленную попытку; каждый выбор сразу записывается в Firestore, а черновик открывается по той же ссылке. Записи идут по очереди, чтобы быстрые изменения не перепутались.
- Страница теста, семейный список и родительский список подписаны на изменения Firestore. Прогресс, завершение и результаты появляются без ручного обновления.
- После необратимой отправки клиент получает ключ и сразу проверяет однозначные ответы. Развёрнутые ответы ждут проверки Codex через Firestore API.
- После проверки полный разбор появляется по той же ссылке; для повторной проверки создаётся связанный тест с новыми заданиями.
- Опубликованные версии тестов неизменяемы. История хранится до удаления взрослым.
- Каждая страница получает предметный пресет и тематическую сцену из поля `visual` в JSON теста. Предустановлены английский, информатика, биология, литература, история, математика, русский, география, физика и химия. `reading` показывает общий текст перед вопросами. SVG/CSS-анимация адаптируется к экрану и настройке уменьшения движения.

## Локальная разработка

```sh
npm install
npm run dev
npm run build
```

Для создания тестов владелец один раз входит в Firebase CLI. После этого `npm run quiz -- create путь/к/тесту.json` использует этот локальный вход. Токен CLI, производный файл `.local/adc.json`, административная ссылка кабинета и токены личных списков хранятся только в игнорируемой Git папке `.local/`. Ученическую ссылку передают Пете, родительскую — взрослому; публикация любой из них в открытом репозитории даст доступ к соответствующим тестам любому читателю.

Первые личные списки наполняются командой `npm run quiz -- board-add .local/learner-board-seed.json`. Manifest — закрытый JSON-массив объектов `{ "token": "...", "previewToken": "...", "description": "..." }` в требуемом порядке. Команда проверяет существование назначений и выводит ссылки `#/my/…` и `#/review/…`. После этого новые назначения через `quiz create` добавляются в оба списка автоматически. Изменение самого теста не требуется; описание в списке можно уточнить в manifest без изменения опубликованного задания.

Правила Firestore, запрещающие просмотр списков и повторную отправку, должны быть опубликованы до выдачи первой ученической ссылки. Cloud Functions и тариф Blaze не используются.

## Публикация

Сайт доступен по адресу https://rubaxa.github.io/education-quizzes/. Команда `npm run publish:pages` собирает сайт и публикует результат в ветку `gh-pages` без GitHub Actions. Если исходники сайта не менялись с прошлого выпуска, сборка пропускается. `npm run publish:pages -- --dry-run` только сообщает, нужен ли выпуск. Для прямой отправки чистой ветки `main` и последующей публикации есть `npm run push:publish`. После слияния pull request нужно обновить `main` и выполнить `npm run publish:pages` отдельно. Правила Firestore публикуются отдельно через Firebase CLI (`firebase deploy --only firestore:rules --project education-9d7c6`).

## Проверки

`npm run check` запускает линтер, тесты и production-сборку. При установке зависимостей `prepare` устанавливает Lefthook; если npm заблокировал установочные скрипты, выполните `npm run prepare` вручную. Хуки проверяют пробелы и линтер перед коммитом, формат Conventional Commits в `commit-msg`, а полный набор проверок перед push.
