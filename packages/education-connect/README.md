# education-connect

Локальное подключение учебного источника к Education. Первая поддерживаемая система — МЭШ. Команда устанавливает пакет из публичного npm; для передачи данных требуется действующее приглашение и опубликованные правила Firebase.

```sh
npx education-connect --invite <одноразовый-код>
```

Нужен Node.js 20 или новее и интерактивный терминал. Логин виден при вводе; пароль и SMS скрыты. Диагностика называет этап, HTTP-статус и код из безопасного списка; тела ответов, URL с кодами и секреты не выводятся. Программа проверяет приглашение, запрашивает логин mos.ru, пароль и SMS только локально, сверяет родительскую роль и найденных детей. Перед передачей она явно сообщает, что оператор Education сможет повторно читать доступные этому взрослому учебные данные МЭШ. Отмена на этом шаге ничего не отправляет.

После согласия пакет отправляет в Firebase **только шифрованный пакет действующих полномочий**. Для каждого приглашения оператор создаёт отдельную пару ключей X25519; в Firebase хранится открытый ключ, закрытый остаётся в локальном реестре оператора. Обменный ключ выводится через HKDF, данные шифруются AES-256-GCM с привязкой к коду приглашения. Пароль и SMS-код не включены в пакет. Принятое подключение удаляет шифрованный пакет из Firestore, а доступ сохраняется в закрытом локальном хранилище оператора. Право на дальнейшее чтение МЭШ можно прекратить, отозвав доступ у источника и удалив локально сохранённые полномочия.

Команды оператора выполняются из корня `education-quizzes`:

```sh
npm run connect -- issue [--family <familyId>] [--days 7] [--delegates 0]
npm run connect -- list
npm run connect -- revoke <одноразовый-код>
npm run connect -- receive <одноразовый-код>
npm run connect -- disconnect <parentPersonId>
npm run connect -- seed-current <familyId> <childId> <parentPersonId>
```

`seed-current` однократно связывает уже существующих ребёнка и взрослого с их ID МЭШ, чтобы новое подключение сохранило их профили. Приглашение в существующую семью принимается только при совпадении хотя бы одного подтверждённого ребёнка МЭШ. `revoke` закрывает приглашение и удаляет ожидающий пакет; `disconnect` удаляет сохранённые локально полномочия МЭШ, но не стирает уже опубликованные учебные данные и не отзывает личную ссылку Education. Пакет и операторский код используют один адаптер МЭШ: `lib/mesh.mjs`.

Параметр `--delegates` сохраняет выделенный лимит на будущее; самостоятельная выдача приглашений взрослым пока не включена. Оператор запускает синхронизацию вручную. Подключение нескольких семей само по себе ещё не запускает их общий цикл обновления дней и оценок.

Диагностическая сборка0.1.1 может передаваться как локальный tarball и запускаться
через `npx --yes --package=/absolute/path/education-connect-0.1.1.tgz education-connect --invite <код>`.
Сборка пакета не означает публикацию новой версии в npm или восстановление МЭШ.
Повторный вход подтверждается только после приёма зашифрованного пакета, проверки
принадлежности аккаунта и свежего чтения источника. Старый код приглашения при
неудачном входе не расходуется; пароль/SMS не нужно присылать в чат.

Локальный запуск из checkout Education: `npm run connect:diagnose -- --invite <код>`.
Он использует текущие файлы без npx, скачивания или публикации новой версии.
`npm run connect:diagnose -- --check` проверяет только среду и не начинает вход.
