# Критерии до зачёта и наблюдения после проверки

## Независимая опись критериев {#criteria}

До содержательного вердикта сохраняется закрытая опись точного задания: ID, ревизия,
отпечаток назначения, все назначенные источники и их полный текст инструкции.
Каждый фрагмент размечается как требование с ID критериев либо как контекст с причиной.
Разметка обязана воспроизводить исходный текст без пропусков. Каждый критерий имеет
устойчивый ID, действие, точную цитату, обязательность и адресный навык.

Опись хранится отдельно от результата в
`dayTaskGuides/{studentToken}/items/{taskId}/criteriaContract/current`, её версии —
во вложенной истории. Перезапись или удаление родительского гида не удаляет эту опись.
Проверяющий
не выбирает удобное подмножество после просмотра работы. Публикация любого нового
зачёта сравнивает полный набор findings с сохранённой описью и отпечатком актуального
назначения. Ошибка, неизвестность или пропуск обязательного критерия запрещают verified.
Без установленного критерия допустим cannot-assess; это не обвинение ребёнка и не зачёт.
Каждый обязательный finding связан через stageId с видимым items-пунктом. Итог этапа
совпадает с совокупностью его критериев: нельзя показать все зелёные этапы при
неверной теме письма. Отпечаток назначенных материалов обязателен; отсутствие поля
не позволяет перепривязать старую транскрипцию к изменившемуся файлу. Legacy-ссылка
без sourceRef учитывается по URL, а не исчезает из описи.
Источник-материал сам по себе не работа. Ранее сохранённые результаты не переписываются.

Структурный барьер доказывает охват сохранённой описи и неизменность входа. Сверка
транскрипции с оригиналом и смысловая полнота выделения требований остаются отдельной
ответственностью проверяющего; произвольный флаг не является доказательством этой сверки.

## Закрытое наблюдение знаний {#knowledge}

Публикация результата сохраняет адресное наблюдение в семейной истории знаний в той
же атомарной записи: владелец, задание, попытка, ревизия источника, критерии/навыки,
вывод по каждому критерию, ссылки на свидетельства и уровень помощи. Повтор не создаёт
вторую попытку; коррекция даёт новую запись и сохраняет предыдущую. Наблюдение не
равно mastered. Микроответ относится только к текущему переходу, не ко всему заданию.
Закрытые ключи, критерии и наблюдения не попадают в ученические документы.

## Сценарии и связь с UI Kit {#scenarios}

Для каждого предметного правила показываются настоящий переиспользуемый компонент,
обе роли, состояния, ID узла/перехода, ближайшая спецификация и основание решения.
Примитив и составная карточка — разные уровни каталога. Каталог работает на условных
данных без семейных сетевых чтений. Перестановка дизайна не меняет критерии, источники,
статусы и действия. Полнота покрытия определяется реестром правил, а не ручным списком
нескольких удачных примеров.
