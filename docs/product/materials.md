# Учебные материалы семьи

Семья передаёт своё издание учебника; система связывает задание с точными страницами и показывает доступные семье материалы. Общий архив дедуплицирует оригиналы и не заменяет семейного основания доступа.

## Подтверждённый сценарий

Загрузка полного PDF → проверка издания/хэша → общий индекс → разрешённая семейная проекция → страницы конкретного задания. Лист учителя и учебник имеют разные основания права.

## Контракты и реализация

Детальные состояния, данные, ошибки, ограничения и кодовые границы принадлежат [модулю](../modules/materials/README.md); документ сохраняет пользовательский результат и не дублирует модульную спецификацию. Сводное состояние существующих возможностей сохранено в [предыдущем индексе](../audits/product-spec-index-2026-10-16.md).
