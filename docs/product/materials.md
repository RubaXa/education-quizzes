# Материалы и страницы учебников

Связанные контракты: [страница дня](day-page.md), [хранение](storage-privacy.md), [источник дневника](../architecture/school-diary-port-adapter.md). Карта: [README](README.md).

<a id="source-metadata"></a>
## Точный источник

Связь задания с учебником хранится в закрытом `.local/material-pages.json`: издание, точная печатная и PDF-страница, задача и короткая сверенная цитата. Этот файл не входит в Git. Отрицательный OCR-поиск не доказывает отсутствия текста; внешний материал подписывается отдельно и допускается после проверки полного оригинала. Если точной страницы нет, карточка сообщает о пробеле.

<a id="page-publication"></a>
## Публикация отдельной страницы

`storage/material-pages.mjs` получает исходный PDF из закрытой библиотеки, сверяет страницу с индексом и готовит PNG в игнорируемой `.local/`. `scripts/storage.mjs sync-pages` загружает выбранные страницы на Яндекс.Диск, проверяет содержимое и сохраняет индивидуальные URL в закрытом реестре. В исходный Git и ветку сайта PNG, PDF и миниатюры не входят. Firestore получает ссылку и метаданные источника, но не байты страницы.

<a id="material-reader"></a>
## Ридер

`MaterialReader` группирует страницы, показывает миниатюры и встроенный просмотр с номером, стрелками, свайпом и увеличением. `src/lib/yandexPublic.ts` получает публичный предпросмотр по отдельной ссылке Диска без OAuth-токена. Запрос изображения не передаёт `Referer` сайта: загрузчик Диска отклоняет такой запрос кодом 403. Если браузер всё же не может показать картинку, пользователь видит ссылку на оригинал. Ссылка с доступом по владению может быть переслана; [граница доступа](storage-privacy.md#privacy-boundary) остаётся отдельным правилом.
