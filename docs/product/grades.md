<a id="grade-badge"></a>
## Метка предмета

`GradeBadge` показывает датированный средний только при подтверждённых данных по предмету. Чистая `5,00` получает короткую позитивную метку; при достаточном запасе она остаётся спокойной. Раскрываемый сценарий появляется при риске снижения и только тогда, когда все нужные отметки и веса воспроизводят показанный средний. Если сверка не пройдена, прогноз не показывается.

Выбор следующей отметки и веса показывает условное изменение среднего и число пятёрок до рабочего ориентира. Порог и вес — настройка сценария, не правило школы и не прогноз годовой отметки. Для предмета без подтверждённого среднего нельзя подставлять ноль или пятёрку.

<a id="dashboard-grade-list"></a>
## Оценки на dashboard

Dashboard показывает **все предметы с опубликованным средним**, а не только несколько с флагом риска. В каждой строке виден предмет и средний балл; нажатие раскрывает все оценки и их веса из сохранённого среза Firestore. Чистая `5,00` получает спокойную позитивную метку. Если у оценки нет сохранённых даты и типа работы, интерфейс не придумывает их и прямо указывает это в раскрытии.

Под списком указана дата среза МЭШ и объяснено, что открытие страницы не запускает запрос в МЭШ: новые отметки приходят после синхронизации и публикации данных. Если для текущего дня ещё нет документа, dashboard берёт последний доступный документ дня не позднее сегодняшней даты и сохраняет его исходную дату среза. Не называть такой срез оценкой «за сегодня», текущей годовой отметкой или живым журналом МЭШ.
