# Отдельная проверка каждого требования МЭШ

## Основание

Родитель 16.10.2026 запросил повторную сверку № 218/223 и понятный одинаковый для предметов разбор: что назначил МЭШ, что добавляет материал, что видно в работе ребёнка и почему получен статус. Предыдущий общий текст скрывал подтверждённый № 218 за неизвестным № 223.

## Было → стало

`src/components/WorkReview.tsx`, `src/DayPage.css`: общий текст и закрытый список пунктов → открытая плоская трасса по каждому обязательному номеру. `src/components/ParentTaskGuide.tsx`: «проверка пока не завершена» для уже просмотренного обрезанного фото → «разбор завершён · часть работы не видна». `src/DayPage.tsx`: родительский разбор с трассой всегда доступен. `src/lib/dayStore.ts`, `storage/review-projection.mjs`: тип и белый список безопасных полей трассы. `storage/review-requirements.mjs`, `scripts/submissions.mjs`: валидация соответствия МЭШ, учебнику, фото и вердикту перед записью.

## Действия и роли

Родитель и ребёнок видят один и тот же вывод по назначенным номерам. Родитель отдельно видит закрытый маршрут помощи и может изменить семейную обязательность дополнительных действий учебника. Невидимый номер получает «не можем установить по фото», без требования переписать уже подтверждённый номер.

## Проверки

`storage/review-requirements.test.mjs` защищает соответствие источников и статусов. `storage/review-projection.test.mjs` защищает приватность. `src/components/WorkReview.requirements.test.tsx` защищает двухномерную карточку при наличии общего текста. Полный `npm run check` и обратная сверка опубликованного Firestore завершают выпуск.

## Согласование

Прямой запрос родителя в текущем разговоре: заново перепроверить и показать структурный разбор с происхождением требований и причиной отсутствия зачёта.
