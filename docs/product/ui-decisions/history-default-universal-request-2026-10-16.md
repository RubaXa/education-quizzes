# Закрытая история и универсальный запрос продолжения

## Основание

16.10.2026 родитель прямо исправил два дефекта: история не должна быть раскрыта по умолчанию; кнопка нового теста должна быть всегда, состав продолжения учитывает все предыдущие попытки по той же логике, что автоматическое создание. Это уточняет прежний выпуск, который ошибочно отложил100%. Контракты: [цепочка](../quiz-chain-proposal.md), [граф](../assessment-decision-graph.md), [тесты](../quizzes.md).

## Было → стало

Явный open у details → исходно закрытая история. Ограничение points<max и отбрасывание нуля ошибок → иконка родителя при любом результате; доступна после проверки, включая100%. При отсутствии проверки, существующем продолжении или запросе видна неактивная иконка с пояснением. Отдельного нового блока нет, цвет и сетка прежние.

Только последняя попытка → единый детерминированный план всей причинной цепочки. При ошибках сохраняется адресный объём; после100% — исходный охват всей темы, до трёх исторических слабых групп, отдельное повторение и перенос. Новое подтверждение continuation обязательно для create/revise-open. Неверный fingerprint, пропущенный слот или неполная матрица блокируют запись. Состав формулировок проверяет оператор, автоматический банк ещё не реализован.

Файлы: `src/components/QuizCard.tsx`, `src/lib/homeworkStatus.ts`, `assessment/quiz-lineage.mjs`, `assessment/decision-graph.mjs`, `scripts/quiz.mjs`, `scripts/sync-queue.mjs`.

## Действия и роли

Родитель отправляет узкий прежний followupRequestedAt/By. Ребёнок не получает эту кнопку. Повторный запрос идемпотентен, результат не переписывается; обязательное задание ждёт продолжения, опциональное не становится долгом. Существующие правила Firestore уже разрешают запрос после100%, расширение прав не требуется. Кнопка сохраняет запрос; готовит и публикует тест Education Sync. История сохраняет обратную сортировку, метки и безопасный разбор. Новых SDK-вызовов нет; чтение предков при публикации переиспользует загруженную текущую попытку, очередь предков не перечитывает.

## Согласование

`direct-request`: родитель 16.10.2026 требует закрытую историю и кнопку нового теста для всех результатов с обработкой всей истории по общей автоматической политике. Исправление явно отвергнутого поведения не требует нового макета. Изменение цвета, сетки или школьной проверки этим запросом не вносится.
