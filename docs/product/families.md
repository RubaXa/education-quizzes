# Семья и подключение

Родитель подключает собственный источник дневника, получает доступ к подтверждённым детям и отдельным ролевым представлениям. Приглашение, совпадение имени или Telegram Start сами по себе не предоставляют семейного доступа.

## Подтверждённый сценарий

Родитель → подтверждённое подключение источника → кабинет с доступными детьми. Несколько взрослых имеют собственные профили и связи. Нельзя создавать ребёнка или семейное право по догадке.
