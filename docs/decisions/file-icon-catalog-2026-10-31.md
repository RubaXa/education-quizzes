# Общий каталог иконок файлов

## Основание

Прямой запрос31.10: показать значки всех файлов, объяснить их происхождение,
сохранить единый стиль, общий переиспользуемый элемент, UI Kit и синхронные спецификации.

## Было → стало

Компонент WorkFilePreview и примеры загруженных документов уже существовали,
но отдельного обозримого каталога всех форматов не было. В UI Kit добавлен раздел
«Иконки файлов»: шесть семейств значков,19канонических форматов и раскрытый пример.
Источник — готовые SVG Lucide React. Продуктовые значки и их внешний вид не меняются.

## Действия и роли

Выбор формата переключает реальный WorkFilePreview. Перечень берётся из общей
workFileTypes; отдельной копии SVG или MIME-списка нет. Цвета и рамки используют --edu-*.
Примеры условные, ничего не отправляют, не читают данные семьи и не меняют её права.
Файлы реализации: `src/UiKit.tsx`, `src/UiKit.css`.

## Проверки

src/UiKit.test.tsx проверяет полный перечень, общий компонент, классы Lucide,
контур2/fillnone и переключение XLSX. e2e/file-icons.e2e.ts проверяет каталог,
переключение PDF/XLSX и отсутствие переполнения при320/390/540/1280px.
Документация фиксирует сопоставление типов/знаков и ссылки между контрактами.
Штатный npm run check остаётся барьером интеграции и выпуска.

## Согласование

Прямой запрос пользователя31.10.2026 разрешает каталог и синхронизацию спецификаций.
UI Kit показывает существующий одобренный вид вложений,не переоформляет карточки задач.
Фактическая публикация подтверждается отдельно.
