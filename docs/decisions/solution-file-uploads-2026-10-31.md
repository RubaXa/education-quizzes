# Файлы решений вместо ограничения фотографиями

## Основание

Прямой запрос31.10.2026: принимать PDF, DOCX, Excel, текстовые и другие файлы задач и решений;
называть действие «Загрузить решение», показывать соответствующий типу значок.

## Было → стало

Выбор image/*, клиентский MIME-список, серверная сигнатура и Rules допускали только фото;
документ попадал бы в компонент изображения. Теперь единый перечень поддерживает фото,
PDF, Office/OpenDocument, RTF, TXT, CSV и MD, сохраняя имя, исходные байты и расширение.
Контрол использует скрепку; карточка решения — нейтральную подпись. Документ показывает
значок типа, расширение, имя и ссылку на оригинал. Фото сохраняет просмотр снимка.
Обычная карточка дня также предлагает «Загрузить решение» и называет документ файлом/работой в передаче и ожидании. Уточнение материала использует нейтральное название файла.
UI Kit принимает реальные локальные документы и не заменяет их условной картинкой.

## Действия и роли

Смешанный выбор создаёт отдельную заявку для каждого файла. Сохраняются роли, family/child/task,
актуальная ревизия, устройство, SHA-256, лимит25МБ и атомарное событие. Исходное имя ограничено160символами
и не влияет на путь или права. Повтор/удаление и переход локальная заявка → сохранённый файл
сохраняют тот же uploadId. Родитель просматривает, ученик загружает. Учебная проверка остаётся
отдельным действием; техническая передача не меняет оценку или учебный статус.

## Проверки

Исходный дефект воспроизведён пятью красными проверками выбора и серверного допуска PDF/TXT/CSV/RTF.
Проверки форматов охватывают MIME/расширение, сигнатуру и хэш, структуру Office/ODF,
отказ бинарному тексту, неподдерживаемому ZIP и превышению ограничений. Реальные компоненты
проверяют смешанный выбор, имя и значки, открытие/закрытие локального и сохранённого документа,
сохранение выбора при передаче, повтор и удаление. Прежний просмотр фото и ролевые ограничения
проверяются существующими интеграциями. Playwright проверяет320/390/540px и обе роли.
Rules evaluator проверяет синтетические случаи новых MIME и отрицательные сценарии прав.
Штатный npm run check остаётся барьером интеграции; выпуск Rules, worker и PWA подтверждается отдельно.
