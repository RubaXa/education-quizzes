# Порядок плана при повторной публикации

## Основание

Автоматический запуск EducationSync возобновился после исправления ожидания источника, но публикация свежего плана остановилась на расхождении порядка предметов. Старое слияние сохраняло прежний порядок и добавляло новые предметы в конец. Строгий preflight сравнивает упорядоченный состав с актуальным источником.

## Было → стало

Слияние использует порядок предметов и заданий из incoming-плана. Существующие объекты объединяются по устойчивым ID с сохранением подтверждённого статуса по прежнему условию. Исторические задания и предметы, отсутствующие в новом плане и явно не снятые, сохраняются в конце; их нельзя незаметно удалить ради прохождения проверки. Смена порядка учитывается как изменение ревизии, повтор тех же данных идемпотентен.

Строгая проверка состава, вариантов и номеров не ослабляется. Ошибка сообщает дату, роль, первый структурный путь и тип расхождения без значений, текста задания или токенов. Несовпадение длины, ID или содержимого по-прежнему останавливает публикацию до записи. Legacy-путь разрешён только при отсутствующем или null отпечатке; пустое и нестроковое значение не отключает строгую сверку.

## Действия и роли

EducationSync готовит источник и выполняет штатный publish-batch с обратной сверкой обеих ролей. Техническая итерация меняет только механику слияния и диагностику; исходные учебные данные, фотографии, доступ и история остаются под контролем их действующих контрактов. Успешные тесты кода не считаются доказательством завершённой публикации данных.

## Проверки

Регрессии проверяют вставку нового предмета, перестановку заданий, сохранение отсутствующей исторической работы и статуса, идемпотентный повтор и строгую сверку результирующей страницы с источником. Отдельно проверяется отказ при потере задания и отсутствие сравниваемых значений в диагностике. Перед выпуском обязательны общий check и штатные Git hooks.

## Согласование

По прямому запросу пользователя исправление выполняет Luna Worker, основной агент проверяет код и фактический автоматический запуск. EducationSync владеет текущей публикацией и ролевым readback. Технический выпуск идёт в main; ручной запуск синхронизации не подменяет доказательство автоматического запуска.
