# Начальная позиция и прокрутка календаря при выборе дня

## Основание

Прямой запрос родителя от 28.10.2026 по трём скриншотам: при открытии календаря выбранная дата должна быть примерно в центре; выбор ближайшей даты не должен менять прокрутку; у края календарь должен плавно перемещаться на несколько дней, чтобы выбранная дата оказалась в центре. Последующее сообщение подтвердило, что исходное поведение осталось неисправленным: устаревший индекс отображал даты, не содержащие сегодняшнюю дату, поэтому выбранная кнопка отсутствовала и первоначальное позиционирование было невозможно.

## Было → стало

Dashboard безусловно переустанавливал `scrollLeft` при каждом выборе и изменении индекса. Теперь начальное позиционирование и решение о прокрутке принадлежат общему `DayCalendar`: первое выставление выполняется без анимации, выбор внутри видимого центрального диапазона оставляет полосу на месте, выбор в краевой зоне вызывает плавный сдвиг примерно на центр карточки. Dashboard дополняет только визуальный диапазон пустыми неподтверждёнными днями до конца шестинедельного окна; данные расписания, заданий, токены и статус полноты не выдумываются. Сохранённая дата в диапазоне остаётся выбираемой даже при устаревшем кэше.

## Действия и роли

Правило реализовано в компоненте `DayCalendar`, используемом dashboard ученика и родителя. UI Kit импортирует тот же компонент и показывает его с синтетическими датами и локальным состоянием; отдельной копии логики нет. Стили и цвета остаются в действующей дизайн-системе.

## Проверки

- Vitest проверяет расчёт позиции: первоначальный центр, неподвижный выбор в середине, обнаружение краевой зоны и расчёт сдвига.
- Тест компонента проверяет первичное выставление прокрутки, отсутствие повторного перемещения на внутренний выбор, плавный сдвиг у края и отсутствие прокрутки при обновлении данных без смены даты.
- Playwright Chromium проходит настоящий `DayDashboard` с детерминированными адаптерами данных отдельно для родителя и ученика. Сценарий использует индекс, устаревший на 12 дней, проверяет стартовое центрирование, выбор соседнего дня без движения и плавный сдвиг при выборе даты у края; дополнительный сценарий проверяет сохранённый выбор после восстановления.
- `npm run check:spec`, `npm run typecheck`, тесты и E2E запускаются на ветке выпуска; UI Kit продолжает ссылаться на общий `DayCalendar`.
