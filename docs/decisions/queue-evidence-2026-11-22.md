# Доказательства старого поручения

## Основание

Основание — прямой запрос семьи22.11: разобрать50поручений и5блокировок,
закрывать выполненное/устаревшее по доказательствам, не запрашивать прежнее.

## Было → стало

`scripts/sync-queue.mjs`: list выдавал старый источник поручения; проверка результата требовала
нескольких разрозненных экспортов. Стало: evidence по одному ID перечитывает
адресные данные с проверкой владельца. Педагогическое решение остаётся агенту;
вывод не означает зачёта и не имеет права автоматически закрыть поручение.
`sync/queue-evidence.mjs` собирает эти данные без записи.

24.11 обнаружено на свежем разборе: одно фото содержит другие номера, чем
кнопка загрузки. `storage/review-coverage.mjs` подтверждает опубликованные
вердикты каждого coveredTaskId с точным uploadId, включая историю. Scan и
разрешение старого поручения в `scripts/sync-queue.mjs` используют это доказательство,
сохраняя неизвестный результат исходного номера. Метка reviewed сама по себе
не закрывает поручение; событие разбора фото не является зачётом задания.

## Действия и роли

UI, обязательность, фото, попытки, оценки и источники не меняются. Закрытые
ответы доступны только операторскому CLI, без нового клиентского пути.

## Проверки

Проверки: чужой владелец отвергается до чтения private результатов; связанные
reviewed фото и partial сохраняются; соседние фотографии не попадают в пакет.
Для теста проверка владельца назначения предшествует чтению ключа и обеих проверок.
Окончательное закрытие отдельно подтверждается штатными finish и readback.
Регрессии: два покрытых номера при неизвестной точке загрузки; отказ при отсутствии
любого результата или другом uploadId; сохранение проверенного фото в истории.

## Согласование

Прямое поручение пользователя22.11 разрешает разобрать оставшиеся50поручений
и5блокировок. Экспорт доказательств — необходимая read-only часть этой работы.
Текущий dispatch24.11 требует разобрать полученные фото, сохранить реальные
результаты и закрыть выполненные поручения по доказательствам без повторного запроса.
