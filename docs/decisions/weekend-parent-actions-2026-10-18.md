# Одинаковые команды родительского разбора в дне и выходном блоке

## Основание

Родитель прислал экран PWA: закрытый разбор доступен, «Подсказка» открывает текст, но отправка отключена. Воспроизведено без отказа Firestore: WeekendMathSlot вообще не передавал onSendGuidance. Этот конкретный симптом не означает отсутствия родительской роли.

Git: ab5793d от10.10 ввёл общий ProblemTaskCard. Коммит0adf7b5 от13.10 добавил dayGuidance/ParentTaskGuide, подключил историю, отправку и выбор этапа в DayPage, но в WeekendMathSlot передал только guide. Последующие изменения до main5bf25f9 сохранили пропуск. Общий внешний вид не обеспечил полноту действий. Причина другой роли конкретного Chrome из этого факта не следует.

## Было → стало

`src/lib/useTaskGuidance.ts` связывает исходный studentToken, историю выпущенных этапов и существующую sendDayGuidance. Одна подписка на контейнер, фильтрация по taskId, готовность истории и команда подготовленного этапа. Scope включает роль и token; поздний callback закрытого scope игнорируется. URL/ширина/PWA роль не определяют.

`src/DayPage.tsx` использует этот контроллер вместо собственного подключения. `src/WeekendMathSlot.tsx` получает те же guidance/ready/onSendGuidance и подключает существующий recordStageChoice для применимых проверяемых этапов. Ребёнок видит отправленные фрагменты в прежнем TaskGuidance. Новые экраны, кнопки, подписи и макеты не вводятся.

## Действия и роли

Команда доступна родителю с подготовленным guide и загруженной историей. Отправленный этап закрывает обе команды по существующей политике; hint и reveal требуют явного выбора. Ученику не выдаются закрытый guide и соседние фрагменты. Переключатель этапа сохраняет прежнюю применимость и не имеет видимой подписи; математика нового переключателя не получает.

Коллекции, ID, тексты, атомарный batch помощи+inbox и Security Rules не меняются. Weekend читает ту же dayGuidance исходного задания, события не копируются. Одна дополнительная узкая подписка нужна для получения помощи ребёнком и защиты родителя от повторной отправки; отдельных подписок на каждый номер нет. Бюджет обычного дня прежний. Отправка сохраняет адресные проверки актуального guide, владельца и получателей. Агент не посылает реальному ребёнку тестовый фрагмент без поручения.
