# Общий архив открытых олимпиадных первоисточников

## Основание

Пользователь27.10передал полный сборник и прямо потребовал сохранять найденные
открытые условия/ключи/методики в общей доступной библиотеке, проверять по
точному первоисточнику и брать из него ответы с подтверждённой применимостью.

## Было → стало

Общий каталог публиковал ученические учебники; найденные методики могли
оставаться лишь ссылкой в случае. scripts/storage.mjs теперь имеет адресный
sync-references; storage/public-references.mjs проверяет явную регистрацию,
PDF/SHA и индекс, публикует общий оригинал и перечитывает каталог/страницы.
Одинаковый повтор не создаёт новую копию или запись. Новый экран не добавлен.

## Действия и роли

Только teacher-guide с public_reference:true, публичным URL и sharing_basis
допускается в этот маршрут. Личные фото, задания и учебники не расширяют
доступ. Firestore Rules не меняются: каталог операторский, PDF доступен всем
по публичной ссылке. Ссылки на ответы не вставляются автоматически в
ученическую карточку. Применимость ключа и расхождения проверяет оператор.

## Проверки

storage/public-references.test.mjs: нет регистрации, подмена PDF/индекса,
выход из library, URL с credentials, публикация/readback, повтор без записей.
Сам приложенный PDF сравнивается с авторской публикацией по SHA; страницы
условий и решений сопоставлены визуально. Приватные оригиналы не публикуются
командой sync-references, если не прошли отдельную явную регистрацию.

## Согласование

Прямая просьба пользователя27.10.2026: строго сверять олимпиадные задачи по
оригинальным решениям, сохранять все такие открытые документы в общей,
сразу доступной всем библиотеке. Публичный GitHub-выпуск кода этим отчётом
не заявляется; источник публикуется отдельно штатным CLI.
