# Переносимый формат таблицы

## Основание

При адресной записи реального guide сервер отклонил comparison.rows[][] как invalid
nested entity. Проверка браузера доказывала отображение, но не возможность хранения.
Firestore Standard запрещает непосредственный массив внутри массива.
[Первичный источник](https://firebase.google.com/docs/firestore/manage-data/data-types).
Первый guide записан успешно, остальные оставались прежними после остановки ошибки.

## Было → стало

Общая таблица использует rows:[{cells:[...]}]. Валидатор, тип, renderer и примеры UI Kit
согласованы; неизвестные поля строки отклоняются. Порядок и текст ячеек не меняются.
Редактор guide проверяет массивы и глубину, оставляя место для закрытого архива guideEdits.

Затронутые файлы:
- `packages/education-presentation/review-content.mjs`
- `src/components/ReviewBrief.tsx`
- `src/lib/reviewBriefExamples.ts`
- `storage/parent-guide-edit.mjs`

## Действия и роли

Права доступа, раскрытие и источник прежние. Семейные страницы, проверка и история
попыток не пишутся. Остальные шесть guide-пакетов применяются со своими прежними fence;
уже записанный первый guide повторно не пишется. Прежние guide сохраняются в архиве.

## Проверки

RED: валидатор отвергает правильную строку-map и принимает вложенный массив.
GREEN: каноническая таблица проходит, вложенный массив и закрытое поле отклоняются;
редактор отвергает непереносимые и слишком глубокие структуры до транзакции.
Полный npm run check, production Chromium и адресная запись/readback обязательны.

## Согласование

Исправление необходимого пути хранения прямо запрошенных семи методических разборов.
Пользователь отдельно разрешил production rules PR103; это исправление их не меняет.
Новых ролей, получателей, оценок и требований к ребёнку нет.
