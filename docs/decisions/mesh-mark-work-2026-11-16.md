# Прямое получение школьной работы

## Основание

Родитель16.11 просит разобрать контрольную и прямо указывает: фото уже в МЭШ,
использовать существующий прямой вход без браузера и повторных семейных загрузок.
Предметная сводка не содержит оригиналов, а has_files может быть false при
непустом result_files. Последняя лента marks не является срезом за переданную дату.

## Было → стало

Добавлены штатные mark-feed и адресный mark-details с бинарным скачиванием,
проверкой идентичности, SHA и сохранением прежних байтов. Контракт —
[порт дневника](../modules/school-diary/README.md#diary-adapter).
Отдельная лента долгов не подменяет подтверждённый числовой журнал; её
автоматическое подключение к полному циклу не заявляется как сделанное.

## Действия и роли

Прежняя verifyAccess подтверждает того же ребёнка и родителя. Фото остаются
закрытыми; ключ не отправляется стороннему origin, редиректы не выполняются.
Ни отметки учителя, ни зачёт ДЗ не меняются из-за нового чтения. Browser и новый
вход не требуются. Дата и ID ответа должны совпасть с адресным запросом.

## Проверки

Unit: чужой origin, не изображение, обязательный ID, другая дата/ID, recent-feed
scope, фото при has_files=false и сохранение разных версий файла. Живое чтение
подтвердило два оригинала одной контрольной и отдельную запись долга; содержимое
проверено визуально. Полный npm run check перед коммитом.

## Согласование

Прямой запрос родителя16.11.2026 в текущем чате: скачать МЭШ и фото работы без
браузера. Публикация операторского исправления разрешена действующими правилами.

Изменённые границы: `diary/cli.mjs`, `diary/application/mark-details.mjs`, `diary/application/mark-files.mjs`, `packages/education-connect/lib/mesh.mjs`.
