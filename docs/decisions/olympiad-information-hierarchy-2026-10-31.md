# Читаемая первая часть страницы олимпиады

## Основание

Родитель прислал реальную мобильную ФЕТТ и отверг оформление: обратная ссылка выглядит
случайно, заголовки не видны как заголовки, пояснения повторяют друг друга. Попросил
исследовать структуру информационных сайтов. Исследование NN/g/GOV.UK/W3C связано
с общим контрактом; чужой визуальный стиль не копируется.

## Было → стало

Навигация вынесена перед карточкой, используется существующая Button и Lucide.
Общий OlympiadOverview задаёт видимый h1 и метаданные, прямые переходы к своим разделам
перед справочным текстом. Предмет/сезонный суффикс переносится только при точном
совпадении; имена не обрезаются. Общий OlympiadSchedule сохраняет compact-каталог,
а в полном виде разделяет ближайшее событие, участие и два раскрытия: все условия
и общий план. Убраны повтор schedule-даты и текст про отсутствующий здесь тумблер.
Регистрационное ограничение/неизвестное остаётся видимым. Секунды, часовой пояс,
предварительность и источники сохраняются. Длинный реальный календарь добавлен в UI Kit.

Затронутые файлы:
- `src/components/OlympiadOverview.tsx`
- `src/components/OlympiadOverview.css`
- `src/components/OlympiadPage.tsx`
- `src/components/OlympiadSchedule.tsx`
- `src/components/OlympiadSchedule.css`
- `src/UiKit.tsx`
- `scripts/check-olympiad-overview-viewport.mjs`

## Действия и роли

Переход на главную использует прежний canonicalToken. Локальные переходы прокручивают
и фокусируют раздел без смены hash и потери состояния. Отсутствующий раздел не получает
пустую кнопку. Доступ, выбор подготовки, семейные задачи, история независимо от выбора,
личные notes/parentNotes, файлы и зачёты не меняются. Регистрация не выполняется в Education.
Новых чтений Firestore и правил доступа нет. Подключение отдельного персонального блока
из параллельного согласованного PR проверяется в составе общего финального main.

## Проверки

Unit-проверки подтверждают перенос только точного суффикса, сохранность условий,
разделение данных/действий и фокус без смены route. Прежние ролевые integration-сценарии
сохраняются. Обязательный Chromium использует все19 реальных общих календарей и настоящий
production CSS на320/390/540/1024px, проверяет размеры заголовка/текста, доступность
переходов, неизвестные даты, закрытые и открытые подробности, клавиатуру и крупный текст.
Полный npm run check и живой родительский/ученический сайт обязательны перед итогом.

## Согласование

Прямое требование родителя исправить явно отвергнутый экран и исследовать читаемую
подачу даёт основание этой коррекции. Спецификация и UI Kit обновляются одновременно.
Общий выпуск выполняет один согласованный publisher после объединения коротких PR.
