# Закрытый разбор рядом со связанным тестом

## Основание

При живом readback английской попытки найдено: результат теста виден, но общий
ранний return для read/check со связанным QuizLineageCard скрывает весь taskCard,
включая уже подготовленный закрытый ParentTaskGuide. Наличие guide в базе не
означает видимость взрослому.

## Было → стало

src/DayPage.tsx по-прежнему не повторяет исходную карточку и тест. В той же ветке
сохранён родительский ParentTaskGuide после цепочки, если guide загружен по роли.
Переиспользуется существующий компонент с его раскрываемыми этапами и CSS.
Нет нового дизайна, полей, запросов или подписок.

## Действия и роли

Guide читается существующим закрытым watchDayTaskGuides только для взрослого.
В ученическом рендере return остаётся пустым, даже если в тестовой памяти есть
guide. Полные ответы не передаются в публичный документ или ученику. Это просмотр,
не новая работа, не автоматическая отправка помощи и не изменение зачёта.

## Проверки

src/DayPage.assignmentQuiz.integration.test.tsx проверяет настоящий DayPage в обеих
ролях: одна цепочка, нет дублирующей карточки, полный guide виден ровно родителю.
Фикстура намеренно содержит guide и в ученическом сценарии, проверяя границу.
После выпуска нужен живой родительский и ученический readback того же дня.

## Согласование

Продолжение прямого поручения родителя проверить весь путь до видимого полного
родительского разбора и исправлять обнаруженные проблемы; текущий dispatch
требует обе ролевые проекции. Другие action поколения не обрабатываются.
