# Скорость внутри панели аудиоплеера

## Основание

Прямое уточнение родителя 22.10.2026 по скриншоту UI Kit: выбор скорости должен находиться внутри плеера рядом с громкостью; отдельный контрол под ним неудобен. Это заменяет первоначальное решение об отдельном select в спецификации аудиобиблиотеки.

## Было → стало

`src/components/AudioPlayer.tsx` выводил отдельный select и при каждом play присваивал его значение playbackRate. Это дублировало встроенное меню и сбрасывало сделанный в нём выбор. Остаётся одна нативная панель: в Chromium меню «⋮» рядом с громкостью содержит «Скорость воспроизведения». Убраны отдельный select, его состояние и присваивание playbackRate при play. Выбор в нативной панели сохраняется после паузы. `src/components/AudioPlayer.css` удаляет стили отдельного контрола; выбор записи в AudioLibrary сохраняет оформление. Настройки и вид нативной панели определяет браузер, компонент не обещает одинаковое меню на всех платформах.

## Действия и роли

Один компонент меняется одновременно в ДЗ, библиотеке и UI Kit для родителя и ученика. Сохраняются ленивая загрузка, отсутствие autoplay, перемотка, громкость, пауза конкурирующей записи, повтор ошибки, освобождение Blob и ссылка на Диск. Семейные права, файлы на Диске и связи материалов не изменяются.

## Проверки

`src/components/AudioPlayer.test.tsx`: регрессия отсутствия отдельного select и сохранения playbackRate после play/паузы/повторного play; прежние проверки загрузки, ошибки, смены записи и конкурирующего звука. До исправления тест воспроизвёл отдельный select. Полный `npm run check` завершён успешно: 242 файла, 1499 тестов, lint/spec/read-index/build. Встроенное меню проверено через реальный AudioPlayer на 320/390/540 px: выбор 1,25× применяется, повторный play сохраняет 1,25×, отдельного select и горизонтального переполнения нет. Проверка в Chromium не подтверждает одинаковый вид меню других браузеров. Выпуск этой итерации ещё не выполнен.

## Согласование

direct-request: родитель прямо потребовал убрать внешний выбор скорости и использовать панель плеера 22.10.2026. Автоматическая проверка отклонила новые координационные сообщения другим чатам как выходящие за разрешение для PR #48. Подготовка изолирована; следующий выпуск требует разрешённой координации по deployment contract.
