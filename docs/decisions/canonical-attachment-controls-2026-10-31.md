# Канонические контролы вложений и точный пример

## Основание

Родитель31.10 заметил,что показанный скриншот не совпадает с действующими контролами,
поручил перечитать спецификации/компоненты,проверить декомпозицию и обновить UI Kit.
Аудит подтвердил:отдельный пример использовал compact-галерею выходного листа вместо
обычной галереи дня,а собственная внешняя обёртка не воспроизводила весь контекст страницы.
Сам факт импорта общих компонентов не делал такой снимок точной копией текущего экрана.

## Было → стало

Стили загрузки были разделены между ProblemCard.css и DayPage.css. Они перенесены
в PhotoUploadControl.css без новых размеров/цветов. Существующая миниатюра,выбор и
соседнее компактное удаление выделены в WorkAttachmentThumbnail со своим CSS.
TaskWorkEvidence закрепляет существующую композицию галереи/связанных ссылок в DayPage,
WeekendMathSlot и UI Kit:layout day/weekend обязателен,день не получает случайный compact.

UI Kit показывает оба контекста отдельно,с действующими оболочками и контролами.
Демонстрация не имеет своего CSS для них. Нового вида учебной карточки не вводится.
Часть старых прямых CSS-значений перенесена буквально:равенство иного токена не доказано,
поэтому в рамках декомпозиции не меняются согласованные оттенки и размеры.

Файлы: `src/components/PhotoUploadControl.tsx`, `src/components/PhotoUploadControl.css`,
`src/components/ProblemCard.css`, `src/DayPage.css`, `src/DayPage.tsx`, `src/WeekendMathSlot.tsx`,
`src/components/WorkPhotoGallery.tsx`, `src/components/WorkPhotoGallery.css`,
`src/components/WorkAttachmentThumbnail.tsx`, `src/components/WorkAttachmentThumbnail.css`,
`src/components/TaskWorkEvidence.tsx`, `src/ui-kit/TaskAttachmentsExample.tsx`, `src/UiKit.tsx`.

## Действия и роли

Открыть/закрыть/переключить изображение и документ,выбрать несколько миниатюр,
повторить локальную передачу,удалить точный файл и сохранить выбор при подтверждении
остаются прежними. Быстрый крестик есть только в compact и при разрешённом удалении,
не вложен в кнопку просмотра и скрыт при режиме выбора. У проверенного файла удаления нет.
Права передают контейнеры;общая композиция не повышает их. Ссылка из другого задания
не становится собственным вложением. Изображение показывает превью,иконка остаётся
для файлов без рендеринга. Учебные данные и результаты не меняются.

## Проверки

Существующие проверки DayPage/WeekendMathSlot и WorkPhotoGallery характеризуют допустимое
поведение до декомпозиции. TaskWorkEvidence.test.tsx проверяет обычный/compact состав,
раскрытие,точное удаление,подтверждение и выбор без вложенных кнопок. UiKit.test.tsx
проверяет реальные варианты и роль. e2e/task-attachments.e2e.ts сравнивает вычисленные
стили загрузки/закрытия с действующей письменной карточкой,миниатюру38px,обе композиции,
ошибку,удаление и отсутствие переполнения при320/390/540px. Штатный npm run check обязателен.

## Согласование

Прямая просьба родителя31.10.2026 разрешает аудит,декомпозицию и исправление UI Kit
в этих пределах. Согласованный вид контролов сохраняется;прошлый отдельный скриншот
не принимается новым эталоном. Публикация подтверждается отдельно.
