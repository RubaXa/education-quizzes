# Детерминированная проверка документации перед коммитом

## Основание

Прямой запрос пользователя: проверять структуру документов, обязательные разделы, ссылки и якоря быстрым инструментом на commit hook.

## Было → стало

Проверка графа дополнена явным профилем sections, проверкой H1/H2 и иерархии заголовков. Lefthook pre-commit запускает проверку точного Git index. Пакеты не добавлены. Исполняемые инструменты: `scripts/spec-graph.mjs`, `scripts/check-docs.mjs`. Настройки: `package.json`, `lefthook.yml`. В `scripts/check-privacy.mjs` добавлено узкое исключение только для Markdown-контрактов `docs/modules/materials/*.md`: сканирование содержимого остаётся обязательным, медиа и закрытые каталоги по-прежнему запрещены. Аудит использует нейтральное «учебного помощника», поскольку прежнее слово ложно совпадало с фильтром имён. Существующие бизнес-требования сохранены; frontmatter описывает текущие разделы без переписывания тела.

## Действия и роли

Автор запускает `npm run check:docs`, исправляет ошибку по пути и причине, подготавливает исправления к коммиту. Обязательный локальный hook проверяет индекс независимо от неподготовленных изменений. Локальные hooks могут быть обойдены средствами Git; полная проверка остаётся в `npm run check` и pre-push.

## Проверки

`scripts/spec-graph.test.mjs` и `scripts/check-docs.test.mjs`: структура, отсутствующий раздел, неверная иерархия, ссылка/якорь, staged/unstaged расхождения, удаление цели и полнота карты. `scripts/check-privacy.test.mjs` проверяет разрешённую спецификацию, запрет медиа и сохранение фильтра персональных данных. Статический инструмент не проверяет смысл текста или доступность внешних URL. Сгенерированный граф проверяется полной командой `npm run check:spec`.

## Согласование

Прямая инструкция пользователя 16.10.2026: «должен быть какой-то инструмент, который запускается на хук при комите ... детерминированная ... наличие определенных секций, что ссылки правильно ведут себя». Реализация ограничена документацией и её инструментами.
