# Выходная подготовка через самопроверку

## Основание

Семья14.11.2026 просит показать подготовку к понедельничной контрольной на выходных аналогично спецкурсу. Прежний валидатор и renderer допускали только листы с problems: обычный тест не мог появиться без выдуманного фото-задания.

## Было → стало

Расширяется существующая проекция weekendSlot.taskIds на kind:check с точной парой testToken/testPlacements.taskId. Новая попытка, второй тест или копия ДЗ не создаются.

## Действия и роли

Граница владельца, даты и личного доступа проверяется штатным publisher. Тот же QuizCard получает живые ответы, ручной результат и связанную цепочку. Карточка закрыта по умолчанию через TaskDisclosure; фотографию не требует. Состояние «проверяем» не равно зачёту; продолжение и результат ниже85% сохраняют активность. Прежние листы, фото, зачёты, добровольные номера и оригинальные сроки сохраняются.

## Проверки

Проверки: обе роли, отсутствие фото-контрола у теста, ожидание письменной проверки, скрытие только проверенной завершённой цепочки после границы, валидная/сломанная связь в индексе и регрессии нумерованных листов.

## Согласование

Прямая просьба семьи14.11.2026: сделать дополнительное задание на выходные для подготовки к контрольной по русскому в понедельник аналогично спецкурсу. Тест и ролевые действия используют существующие общие компоненты. Исходящие служебные сообщения между чатами не отправляются.
