# Независимое исполнение пользовательских событий при блокировке МЭШ

## Основание

Аудит 21.10.2026 подтвердил общий blocked/source_unavailable: внешний запрос МЭШ оставался на поколении 19, новые сигналы достигли 162, а незавершённый диапазон пользовательских действий 18–43 оставался за той же блокировкой. Подтверждённый перенос файла и уведомление Telegram не доказывают проверку, публикацию и обновление траектории.

## Было → стало

Ранее blocked общего запроса удерживал все новые пользовательские действия. Для типизированного Mesh-only source_unavailable сохраняется исходный внешний request ID, причина и watermark, а actionLane хранит отдельный ограниченный запрос с зафиксированным диапазоном действий, арендой, fencing token и повторами. Уже накопившиеся действия можно взять после перезапуска worker без нового события. Permission/manual-review и неоднозначные смешанные блокировки автоматически не обходятся.

## Действия и роли

Исполнитель берёт только свой request ID и точный манифест action-задач. Завершение action имеет scope=action и не закрывает внешний запрос МЭШ. Непроверенные задачи, новый диапазон, изменившийся источник и недоступные данные не превращаются в completed. Диагностика status показывает action в pendingKinds, безопасные watermark и состояние actionLane без token или исходного содержимого. Новых подписок и отдельного ядра источников нет.

## Проверки

Предметные регрессии покрывают накопленный диапазон за blocked Mesh, claim/export, запрет complete до done всех заданий, независимое завершение, новые события во время исполнения, повторную доставку, аренды и устаревшие подтверждения. Полный check и штатные Git hooks обязательны перед выпуском. Живая активация runtime подтверждается отдельной закрытой квитанцией; выполнение педагогического цикла требует собственного опубликованного результата и readback.

## Согласование

По прямому поручению пользователя EducationSync ведёт доказательный аудит, эта сессия через Luna Worker исправляет диспетчер, основной агент проверяет интеграцию и выпускает main/runtime. Полный сбор и параллельная публикация сайта ради технической проверки не выполняются.
