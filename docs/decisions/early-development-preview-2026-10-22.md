# Отдельный режим с рождения

## Основание

Текущий прямой запрос родителя о самостоятельном разделе с рождения.

## Было → стало

22.10 родитель прямо поручил разработать раздел с рождения до школы: программа,
дневник, помощь родителям и основания методик. Школьная карточка с отсутствующим
календарём не выражает этот сценарий. Новый контекст не меняет доступ к семейным книгам.

Было: отдельного режима нет; включение младенца обычным add-child создаёт школьную
роль. Стало в локальном предпросмотре: «Сегодня → инструкция → необязательное
наблюдение → дневник», программа и мини-урок родителю. Используется существующий
Shell, Button и дизайн-токены. Новый компонент оправдан новой семантикой наблюдения,
без школьной оценки и статуса выполнения. Никакой live-миграции этим решением не выполнено.

Маршрут доступен только при import.meta.env.DEV; lazy import удаляется production
сборкой. Условный профиль и локальные записи не подменяют рабочую семейную систему.
Готовые идеи ограничены первыми неделями. Весь дальнейший возрастной диапазон —
явно обозначенный план наполнения. Новый видимый блок показывается родителю перед выпуском.

## Проверки

Чистые правила и журнал: earlyDevelopment.test.ts. Полный компонентный путь,
повторное открытие, редактирование и отказ хранилища: EarlyDevelopment.test.tsx.
Реальная мобильная геометрия проверяется на320/390/540px; production не должен содержать
модуль прототипа. Существующий школьный кабинет не переключается на новый режим.
Следующая итерация требует авторизованной модели, CLI, Rules и смешанной семьи;
публикация не подтверждена наличием этого документа.

## Действия и роли

Только взрослый просматривает идеи и сохраняет локальное наблюдение. Ни студенческих grants, ни live Firestore reads/writes не добавлено. Затронуты src/App.tsx, src/components/EarlyDevelopment.tsx, src/components/EarlyDevelopment.css и src/lib/earlyDevelopment.ts.

## Согласование

Прямой запрос22.10: «давай разработаем Раздел именно для дошкольника … Прямо с рождения … дневнике … программу … направляют родители». Он разрешает разработку и конкретный локальный предпросмотр. Визуальное подтверждение нового блока перед выпуском ещё не получено; автоматическая проверка разрешений ранее отклонила внешнюю отправку кода без явного разрешения. Выпуск этим решением не согласован и не заявлен.
