# Компактная панель с прямым меню скорости

## Основание

После постоянной панели родитель отметил удвоенную высоту и крупные переключатели. Три варианта A/B/C отклонены; визуальным ориентиром стал его скриншот прежней округлой строки. Уточнённый работающий макет54px с простым Play и постоянно видимой текущей скоростью рядом со звуком показан22–23.10;23.10 родитель ответил «да». Это уточнение внешнего вида сохраняет ранее принятые один Play, отсутствие «Слушать», постоянную панель и прочерки неизвестного времени. Закрытые изображения/макеты семьи не включаются в репозиторий.

## Было → стало

`src/components/AudioPlayer.tsx` и `src/components/AudioPlayer.css` реализуют общую панель; `src/UiKit.tsx` показывает её без копии HTML.

Два ряда около120px, отдельная подпись и select скорости, постоянный ползунок громкости → одна округлая строка54px: простой Play, время, перемотка, динамик, текущая скорость. Кнопка скорости сразу открывает радиосписок всех5значений; динамик — volume/mute popover. Видимые18px иконки сохраняют44px области касания. Внешние меню не растягивают панель. Громкость зависит от поддержки платформы; физический iPhone проверяется отдельно. Новых библиотек/сетевых чтений нет: Button и Radix уже используются проектом.

## Действия и роли

Одна реализация AudioPlayer для родителя/ученика, ДЗ, библиотеки и UI Kit. Панель видна до первого Play, media element скрыт без controls. Скорость до загрузки/при загрузке/на паузе не запускает звук, применяется после metadata и сохраняется при повторе. Меню имеет радиопункты, клавиатуру/Escape и возврат фокуса. Загрузка с Диска, SHA-256, Blob cleanup, поздние ответы, ошибка/повтор и оригинальная ссылка сохраняются. Данные, PWA, права и runtime не меняются.

## Проверки

RED: после замены ожиданий select на настоящее меню прежняя реализация не выполнила3сценария — выбор до/после загрузки и открытие громкости. GREEN: тесты компонента/UI Kit проходят с реальными Radix порталами, меню выбирает темп до первогоPlay, при загрузке и на паузе; seek/volume/mute/error/lateBlob сохранены. Интеграция дня проверяет обе роли и два вида карточки. Полный `npm run check`:252 набора/1565 тестов, spec/read-index/lint/typecheck/build — успешно на базе48f0acf. Браузерная проверка реального компонента: контейнеры320/390/540px, viewport320/390px без горизонтального overflow; панели54px до/после metadata, кнопки44×44px, playbackRate0,5→0,75 при paused=false и controls=false. Результат выпуска подтверждается source marker/JS/SW readback; физический iPhone этим не считается проверенным.

## Согласование

Прямое «да»23.10 одобряет показанный конкретный макет. Сохраняется прямое разрешение родителя завершать проверенные правки в main и публиковать, координировать все чаты Education. Отдельный checkout от48f0acf сохраняет раннее развитие; активные работы уведомлены, publisher этой итерации — аудиочат, параллельный publish исключён.
