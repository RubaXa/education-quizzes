# Дозирование помощи в карточке задачи

## Вопрос

Как показать точное школьное задание и помочь конкретному ученику начать рассуждать, не сообщив ему решающий шаг до собственной попытки?

## Подтверждения из исследований

1. **Количество помощи зависит от знаний именно по проверяемому навыку.** Обзор экспериментов с Cognitive Tutors называет выбор между сообщением и удержанием информации *assistance dilemma*: единого порога для всех учеников и задач нет. [Koedinger & Aleven, 2007, авторская версия](https://pact.cs.cmu.edu/pubs/Koedinger%20Aleven%2007.pdf), DOI `10.1007/s10648-007-9049-0`.
2. **Избыточная опора может мешать при росте опыта.** Исследования эффекта обращения экспертизы показывают, что полезный новичку подробный разбор становится излишним для подготовленного ученика. Это обосновывает постепенное снятие подсказок, но не даёт готового алгоритма выбора уровня по одному баллу. [Kalyuga, Ayres, Chandler & Sweller, 2003](https://doi.org/10.1207/S15326985EP3801_4).
3. **Ученик должен объяснять собственный ход.** В двух классных экспериментах учащиеся, объяснявшие шаги при работе с Cognitive Tutor, показали более глубокое понимание, чем группа без такого объяснения. [Aleven & Koedinger, 2002](https://doi.org/10.1207/s15516709cog2602_1).
4. **Немедленно верное решение не доказывает долговременное освоение.** Повторное извлечение из памяти улучшало отложенное воспроизведение по сравнению с повторным изучением после первого успеха. Нужны новая самостоятельная задача и поздняя проверка, если продукт заявляет освоение. [Karpicke & Roediger, 2008](https://doi.org/10.1126/science.1152408).
5. **Педагогическое действие должно быть связано с доказательством.** ETS разделяет модель ученика, модель задания, наблюдаемое свидетельство и педагогическую модель, которая определяет способ поддержки роста. [Hansen, ETS, 2011](https://www.ets.org/research/policy_research_reports/publications/report/2011/imbu.html).

## Продуктовый вывод для Education

Точный текст, рисунок и доступный оригинальный файл — неизменяемый слой источника. `Дано / Найти`, выделения, вопросы и обратная связь — явно подписанный слой Education. В ученическом режиме до попытки показывается только оригинал; первый ориентир открывается по просьбе ученика или по подтверждённому педагогическому основанию. После попытки следующая подсказка относится к первому наблюдаемому затруднению и требует нового действия ребёнка. Родитель видит источник, структуру данных и основание выбора помощи отдельно от детской карточки.

## Границы вывода

Исследования не устанавливают для нашего ученика числовой порог «знает на 100%», универсальную задержку перед подсказкой или правило по одной оценке. Выбор уровня помощи — проектное решение, подлежащее сверке на реальных самостоятельных попытках. Один запрос подсказки не доказывает пробел, а исправление после подсказки не доказывает самостоятельное освоение.
