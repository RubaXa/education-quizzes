# Варианты родительской карточки по предметам

Согласованные формы литературы и других предметов перенесены в [действующий граф](../product/card-generation-policy.md#subject-adapters) и [общую модель данных](../product/subject-card-viewmodel.md#viewmodel). Ниже остаётся обоснование выбора; оно само по себе не является критерием учителя.

Статус: **исследовательское основание принятых вариантов**, не действующий критерий проверки конкретной работы и не команда автоматически изменить старые задания. Сверено 12.10.2026 с предметами, встречающимися в локальных днях Education и расписании МЭШ. Реальные карточки наполняются поштучно после сверки источника. Существующая шапка Education, оригинал, фото, статус и права ролей сохраняются.

## Общий вывод из исследований

Нет одного международного шаблона карточки для всех дисциплин или обязательной «нормы дистанционного обучения», предписывающей четыре математических шага литературе. Проверенные общие принципы: понимать точную цель работы, давать обратную связь по наблюдаемому действию и конкретному следующему шагу, оставлять ребёнку возможность использовать обратную связь, не увеличивать число экранов и действий для семьи без учебной пользы. Для письменной работы полезны планирование, создание и пересмотр по конкретному тексту; для понимания прочитанного — вопросы к смыслу и обсуждение; для науки — связь вывода с данными, для истории — критика источника и подтверждение вывода, для географии — вопрос, данные и пространственная интерпретация. Это **основания проектирования**, не критерии учителя к данному ДЗ. Источники: [EEF Feedback](https://educationendowmentfoundation.org.uk/education-evidence/guidance-reports/feedback), [EEF Digital Technology](https://educationendowmentfoundation.org.uk/education-evidence/guidance-reports/DIGITAL), [UNESCO Distance Learning](https://www.unesco.org/en/digital-education/distance-learning-guidance), [IES Secondary Writing](https://ies.ed.gov/ncee/WWC/PracticeGuide/22), [IES Adolescent Literacy](https://ies.ed.gov/ncee/wwc/practiceguide/8), [CAST UDL](https://www.cast.org/what-we-do/universal-design-for-learning/).

Для любой роли: оригинал МЭШ/учителя и семейная страница выше анализа; назначенные действия отделены от методических советов. У родителя — закрытая карта возможного ответа и доказательства проверки; у ребёнка — только назначение и выбранная взрослым помощь. После фото, аудио или текста карта показывает `подтверждено / расхождение / не видно / не читается / допустим иной вариант` с точным местом. Нельзя выводить процент, если число проверяемых пунктов не подтверждено. Подсказки имеют уровни: **навести вопросом → указать место и тип проверки → показать часть структуры или шага**. Готовый ученический текст не создаётся и не отправляется автоматически.

## Предлагаемые формы

| Предмет в проекте | Вариант A: типичная работа | Вариант B: другой результат | Что меняется после ответа ребёнка | Адресная помощь родителя |
|---|---|---|---|---|
| **Русский язык** | **«Карта текста»** для темы, мысли, типа/стиля и плана: исходный текст, вопросы задания, смысловые части с привязкой к абзацам; без готового плана в заголовке. | **«Правило в действии»** для языкового упражнения: конкретная строка → правило из назначенного материала → применение → проверка. Для сочинения отдельная карта функций частей, содержания, речи и грамотности. | Тема/мысль/пункты либо языковые решения накладываются на соответствующий фрагмент; различать неверное, неполное и спорный критерий формы. Не требовать пятого пункта плана без источника. | «Какую часть текста этот пункт объединяет?» → подсветить абзац → показать функцию пункта или применимое правило; полный текст за ребёнка не писать. |
| **Литература** | **«Позиция и опора»** для темы/идеи, характеристики, развёрнутого ответа: тезис → эпизод/деталь → почему он доказывает мысль → вывод. | **«Чтение и понимание»** для назначенных страниц: произведение/страницы, вопрос к смыслу, устная самопроверка, без искусственного письменного результата. | Сопоставлять интерпретацию с текстом произведения, принимать обоснованную иную трактовку; указывать отсутствующую опору или фактическое противоречие, а не несовпадение с одним образцом. | «Какой эпизод поддерживает твою мысль?» → указать место в тексте → показать пример связи мысли и эпизода, но не готовый ответ. |
| **Английский язык** | **«Языковая практика»** для слов, грамматики и рабочей тетради: номер, языковая цель, применимое правило/контекст, короткие решения по номерам. | **«Коммуникативная задача»** для письма/диалога: кому, зачем и что нужно сообщить; функции фраз, понятность, затем форма языка. Для аудирования/чтения отдельная карточка понимания. | Указывать конкретное слово/предложение и тип затруднения (`смысл`, `форма`, `порядок`, `произношение` только при доступном аудио); не оценивать устную речь по фото тетради. | Сначала контекстное слово или вопрос о функции фразы → релевантное правило → один образец **аналогичного**, не того же предложения. |
| **Биология** | **«Понятие ↔ признак ↔ функция»** для выписки и таблицы: пары из назначенных страниц, источник каждой пары, требуемое покрытие. | **«Объясни явление»** для вопросов: наблюдение/данные → биологическая связь → вывод; рисунок или схема остаются оригиналом. | Для выписки отмечать именно назначенные пары, видимые в работе; для объяснения — где связь причинно неверна или не показана. Перефразирование допустимо. | Указать нужную страницу и объект сравнения → спросить о функции одного признака → раскрыть одну подтверждённую пару. |
| **География** | **«Карта и вывод»** для атласа/контурной карты: слой карты, условные знаки/масштаб, место, наблюдаемый рисунок распределения, вывод. | **«Данные и объяснение»** для параграфа/таблицы: вопрос → карта/таблица/текст → сравнение → вывод. Явное ЦДЗ показывает только результат платформы. | Ошибка локализуется в объекте, легенде, направлении, масштабе или выводе; отсутствие карты/источника — ограничение проверки, не придуманная ошибка. | «Что показывает этот знак легенды?» → открыть нужный слой/строку → показать способ чтения одного признака. |
| **История** | **«События и связи»** для пересказа/устного опроса: временная ось, участники, причины, событие, последствия; только то, что спрашивается. | **«Источник и вывод»** для работы с документом: кто/когда/зачем написал → что именно утверждает → чем подтверждается → какие есть ограничения. | Устную готовность не выводить из фотографии; по письменной работе отмечать ошибку даты, последовательности, причины или интерпретации с точной опорой. | Попросить найти опорную дату/фразу → направить к контексту источника → показать одну связь между фактом и выводом. |
| **Труд (технология)** | **«Проект и изделие»**: назначенный продукт, эскиз, материалы, безопасные операции, фото результата; обязательны лишь реально заданные этапы. | **«Правило и применение»** для теоретического упражнения или чертежа: исходная схема → термин/правило → применение. | Отдельно выполнен ли продукт и что видно о процессе; безопасность нельзя объявлять соблюдённой по финальному фото изделия. | Указать на нужный размер/соединение/этап → задать вопрос о следующей операции → показать один образец приёма, если это безопасно и назначено. |
| **ИЗО** | **«Работа и замысел»**: исходный образец или задание, фото работы, назначенные средства (например, композиция/цвет) и объяснение авторского решения. | **«Наблюдение искусства»**: произведение/фрагмент → замеченная деталь → эффект/смысл; разные аргументированные прочтения допустимы. | Не подменять оценку творческой работы сходством с сгенерированным «эталоном»; указывать лишь конкретный назначенный аспект и видимую часть. | Вопрос «на что первым смотрит зритель?» → отметить область изображения → показать один вариант композиционного приёма, не дорисовывая работу ребёнка. |
| **Музыка** | **«Слушаю и различаю»**: произведение/фрагмент, услышанный элемент (ритм, тембр, характер), слова ребёнка с опорой на запись. | **«Исполнение или нотная работа»**: заданное действие, аудио/видео или запись, применимые признаки; без записи исполнения статус качества неизвестен. | Проверять только доступный модальный источник: по тексту нельзя судить о точности пения; мнение о характере произведения допускает объяснённые варианты. | Повторно прослушать заданный фрагмент → сравнить один музыкальный признак → назвать термин после наблюдения. |
| **Физкультура** | **«Факт задания и безопасность»**: что назначено, где и как подтверждается; без домашнего назначения нет долга. | **«Техника/теория»**: если назначена конкретная техника или правило, краткая карточка действия и безопасных границ, без медицинских выводов. | Отдельно факт выполнения, наблюдаемая техника при подходящем видео и неизвестное; никакого автоматического диагноза или «нормы» без подтверждённого критерия. | Напомнить одну точку внимания/правило безопасности, а не задавать ребёнку новое упражнение. |
| **Практикум по решению математических задач** | Тот же математический адаптер `compact/standard/extended`, если задача требует вывода ответа. | Для множества номеров — общий список с раскрытием одного номера; лист практикума привязан к **своему** уроку и сроку. | Сопоставление по номерам и этапам; результаты спецкурса не прикрепляются сюда по сходству темы. | Та же адресная помощь, что в математике, с номером и конкретным этапом. |
| **Неизвестный или пока не разобранный курс** (`РОВ`, `РМГ`, `ИИ 6р` и новые) | **Универсальная карточка**: точный МЭШ, оригинал, требуемое действие и способ предъявления, если подтверждены. | После проверки назначения выбрать существующий адаптер по результату, а не по названию курса; новый адаптер только после источника и обсуждения. | Статус предъявления и конкретное видимое доказательство; без критерия — честное `неизвестно`, без выдуманного вердикта. | Один вопрос к назначенному действию или исходнику; полный образец только при подтверждённом виде работы и решении взрослого. |

Реальные данные сейчас подтверждают, например, план по русскому, тему/идею литературного произведения, биологическую выписку, устный опрос по истории, английскую рабочую тетрадь и слова, географическое ЦДЗ. Расписание содержит и практические предметы, но не каждый из них имеет ДЗ. Некоторые исторические записи имеют слишком общий `kind=check`; этим нельзя обосновывать шаблон карточки, пока назначенное действие не сверено с текстом МЭШ. География в старом источнике встречается с fallback-ID; перед миграцией нужно сохранить связи с её данными.

## Почему предложены именно эти формы

Русский и литература опираются на [федеральные программы русского](https://edsoo.ru/wp-content/uploads/2025/07/2025_ooo_frp_russkij-yazyk_5-9.pdf) и [литературы](https://edsoo.ru/wp-content/uploads/2025/07/frp_literatura_5-9-klassy_2025.pdf), а также на рекомендации [IES по письму](https://ies.ed.gov/ncee/WWC/PracticeGuide/22) и [пониманию текста](https://ies.ed.gov/ncee/wwc/practiceguide/8). Английский разделён по результатам `понимание / производство / взаимодействие / посредничество` в [CEFR Companion Volume](https://www.coe.int/en/web/common-european-framework-reference-languages/cefr-descriptors) и [российской программе](https://edsoo.ru/wp-content/uploads/2025/07/2025_ooo_frp_angl_5-9.pdf). Это не означает, что уровень CEFR или шкала экзамена становится оценкой домашней работы.

Биология сверяется с [программой 5–9](https://edsoo.ru/wp-content/uploads/2025/07/2025_ooo_frp_biologiya_5-9_baza.pdf); связь объяснения с данными соответствует [NGSS science practices](https://www.nextgenscience.org/dci-arrangement/ms-ess3-earth-and-human-activity). Историческая работа с источниками и несколькими обоснованными трактовками согласуется с [федеральной программой истории](https://edsoo.ru/wp-content/uploads/2025/07/2025_ooo_frp_istoriya_5-9.pdf) и [Reading Like a Historian](https://www.inquirygroup.org/history-lessons). Географические карты и данные опираются на [программу географии](https://edsoo.ru/wp-content/uploads/2025/07/2025_ooo_frp_geografiya-5-9.pdf) и [Geo-Inquiry National Geographic](https://education.nationalgeographic.org/resource/geo-inquiry-educator-resources/). Эти зарубежные рамки используются как методическая проверка дизайна, не как дополнительные требования российской школе.

Для практических предметов форма результата и осторожность с оценкой по фото следуют из [программы технологии](https://edsoo.ru/wp-content/uploads/2025/06/20_frp_trud-tehnologiya-5-9-klassy_26062025_itog-na-sajt.pdf), [программы физкультуры](https://edsoo.ru/wp-content/uploads/2025/07/2025_ooo_frp_fizkultura-5-9.pdf) и действующих [программ музыки и ИЗО](https://edsoo.ru/rabochie-programmy/). Для конкретного задания нужны назначение и школьный критерий; список выразительных средств или норм из общей программы не становится автоматической проверкой.

## Порядок обсуждения

Разбирать один предмет за раз на **реальном задании из текущей семьи**: (1) какой результат учитель запросил; (2) что видит родитель до попытки; (3) что меняется после загрузки; (4) как родитель отправляет одну подсказку; (5) где критерий обязательный, а где методическая рекомендация. После утверждения конкретного предмета создать/обновить его спецификацию и лишь затем код. Предлагаемый первый предмет — русский язык, потому что текущий план упражнения 169 уже показал проблему спорного дополнительного требования.
