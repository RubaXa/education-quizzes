# Происхождение и ключи задач спецкурса

## Зачем это нужно

Учительский лист остаётся точным назначением ребёнку. Ранее опубликованный вариант помогает проверяющему найти эталонный ответ, критерии и разные способы решения, а родителю — понять происхождение задачи. Имена, числа, рисунки и даже формулировка могут быть изменены; найденный прежний ответ не переносится автоматически на лист учителя.

## Порядок для каждого номера

1. Сохрани неизменный файл учителя, SHA-256, координаты полного фрагмента и дословную запись. Пометь опечатки оригинала, не исправляй их внутри `original.text`.
2. Ищи точные длинные фразы, редкие объекты и числовую структуру. Затем ищи варианты без имён и чисел: эквивалентное правило, рисунок, класс, соседние задачи. Проверяй лист целиком: единый источник для части номеров не доказывает происхождение остальных.
3. Собери кандидатов с прямыми URL. Приоритет: организатор соревнования/олимпиады, авторский сборник, школа/университет, издатель, методический материал, затем вторичные публикации. Для каждого запиши признаки совпадения и расхождения. Поисковый сниппет используется **только для обнаружения**.
4. Открой полный первоисточник, визуально сравни условие и рисунок, затем отдельно найди ключ и критерии именно этого варианта. `verified` относится к происхождению; `keyStatus: verified` — отдельное утверждение. Название олимпиады, год и класс указывай только из проверенного документа или страницы организатора.
5. В закрытом источник-пакете сохрани варианты, полный ключ/решение, критерии, способ проверки изменённого условия и неопределённость. В родительский документ Firebase попадает краткий `sourceResearch` без ответа; в ученический — ничего из этого слоя. Если ключ недоступен, проверяющий выполняет независимое решение и аудит, честно маркируя его как собственный вывод.

## Найденный кандидат для листа с № 1–7 от 15.10.2026

В [PDF на сайте Сибирского федерального университета](https://dovuz.sfu-kras.ru/upload/iblock/e23/sudaklgthp3d5ceyott7pmhmw1he2fcu.pdf) поисковый индекс показывает формулировки, совпадающие с № 1–4 и № 6 учительского листа. Для № 5 поиск по Белоснежке, числу гномов и формулировке вопроса, а для № 7 — по костюмам и последовательности допустимых номеров не дал надёжного полного документа; их статус `not-found`, а не утверждение о новом авторстве задачи. Полный PDF из текущего окружения не открылся; рисунки, состав листа, год, тип мероприятия, ключи и критерии не сверены визуально. Поэтому для № 1–4 и № 6 `sourceResearch.status = candidate`, `keyStatus = not-checked`; принадлежность к ВсОШ не подтверждена. При следующем доступе к полному документу сначала сверить его с исходным листом, затем повысить статус и только после этого использовать ключ для проверки работы.

## Границы педагогической обратной связи

Найденный ответ нельзя показывать ученику в карточке, отзыве, истории или текстах подсказок. Ученику сообщаются наблюдаемое место расхождения и один следующий вопрос; родителю доступна информация об источнике и степени совпадения. При ответе, совпавшем с ключом, но без проверяемого хода отдельно оценивается полнота объяснения, без требования фиксированного числа строк.
