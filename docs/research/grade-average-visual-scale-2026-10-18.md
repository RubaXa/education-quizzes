# Цветовое представление среднего по предмету

## Источники

- [W3C WAI: Use of Color (WCAG 2.2, 1.4.1)](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html): цвет не должен быть единственным способом сообщить состояние; дополнять числом, текстом, формой или знаком.
- [W3C WAI: Contrast Minimum (WCAG 2.2, 1.4.3)](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html): обычный текст требует контраста не менее 4.5:1, крупный текст — 3:1.
- [IBM Carbon: Status indicators](https://www.carbondesignsystem.com/building-blocks/core/patterns/status-indicators): повторно использовать системные ролевые токены, различать знак/форму и цвет, проверять контраст статуса и поверхности.
- [GOV.UK Design System: Tag](https://design-system.service.gov.uk/components/tag/): один и тот же цвет должен означать одно и то же во всех применениях; смысл тега должен оставаться понятен без одного цвета.

## Выводы

В источниках нет универсальных числовых порогов для «хорошего» школьного среднего или гарантии годовой отметки. Порог успеваемости — локальное педагогическое правило и не должен выводиться из чужой палитры. Для Education следует оставить число главным сигналом, сохранить видимый мягкий фон каждой метки, использовать действующие проверенные пары status-токенов, а пояснение располагать рядом в каталоге. Новые hex-цвета не добавляются.

Здесь две семантики, которые не следует смешивать: тон диапазона среднего (`2…5`) и флаг `watch`, опубликованный данными предмета. Явный `watch` сохраняет приоритет и янтарный тон, даже если диапазонный ориентир выглядел бы позитивнее. `allFives` — единственное основание для ✨; 4,99 само по себе не доказывает, что все оценки — пятёрки.

## Предложенная шкала

| Средний в сохранённом срезе | Пара токенов | Подпись примера | Граница |
|---|---|---|---|
| 2,00–2,99 | `error` | Нужна поддержка | 2,99 → 3,00 |
| 3,00–3,99 | `attention` | Диапазон троек | 3,99 → 4,00 |
| 4,00–4,49 | `neutral` | Диапазон четвёрок ниже выбранного рубежа | 4,49 → 4,50 |
| 4,50–4,59 | `accent` | Уже хорошо | 4,59 → 4,60 |
| 4,60–4,99 | `success` | Устойчиво высокий средний | 4,99 → 5,00 |
| 5,00 + `allFives` | `success` + ✨ после числа | Все отметки — пятёрки | Требует подтверждённого флага |

Пороги 4,50 («уже хорошо») и 4,60 («устойчиво высокий») — предложенные пользовательские ориентиры для визуального чтения, а не формула выставления годовой оценки. До публикации нового смысла в родительской/ученической поверхности требуется предметно подтвердить школьное правило для «твёрдой пятёрки».
