## Межпредметные официальные источники и формы

Каталог фиксирует **куда идти и что проверять**, а не разрешает механически брать вопрос из любого банка. Для нового класса и темы оператор открывает точный раздел и сравнивает его с назначенным семейным учебником и пройденным материалом. Открытый банк не является вариантом контрольной конкретной школы.

| Предмет / действие | Первичный источник для границы содержания и формы | Ограничение |
| --- | --- | --- |
| Все предметы, чтение источника | [Федеральные рабочие программы ЕДСОО](https://edsoo.ru/rabochie-programmy/); [банк читательской грамотности ФИПИ, 5–9](https://fipi.ru/otkrytyy-bank-zadani-chitatelskoi-gramotnosti) | У ФИПИ есть тексты разных предметов; выбор формата не заменяет точный параграф семьи. |
| Русский | [Банк оценочных средств ФИПИ](https://fipi.ru/otkrytyy-bank-otsenochnykh-sredstv-po-russkomu-yazyku) и [программа](https://edsoo.ru/wp-content/uploads/2025/09/01_frp_russkij-yazyk_5-9-klassy_itog-na-sajt_1-2.pdf) | Разделы чтения, письма, слушания, говорения и языка проверяются разными действиями; объём и тема сверяются с МЭШ. |
| Литература | [Программа литературы 5–9](https://edsoo.ru/wp-content/uploads/2025/07/frp_literatura_5-9-klassy_2025.pdf); [методические материалы ЕДСОО](https://edsoo.ru/mr-literatura/) | Вопрос о толковании требует опоры на текст; не объявлять допустимое обоснованное прочтение ошибкой из-за иной формулировки. |
| Математика | [Рекомендации ЕДСОО по оцениванию](https://edsoo.ru/wp-content/uploads/2025/08/matematika_.pdf); [IES для задач 4–8](https://ies.ed.gov/ncee/wwc/PracticeGuide/16) | Учитывать пройденный к дате материал и ход решения; выбор ответа не доказывает вычислительную запись. |
| История | [Банк текущего оценивания 5–9 ЕДСОО](https://edsoo.ru/2024/10/22/bank-zadanij-dlya-tekushhego-oczenivaniya-po-uchebnomu-predmetu-istoriya-5-9-klassy-2024g/) | Источник, хронология и причинная связь — разные цели, требующие разных критериев. |
| География | [Банк текущего оценивания 5–9 ЕДСОО](https://edsoo.ru/wp-content/uploads/2024/10/bank-zadanij-dlya-tekushhego-oczenivaniya-po-uchebnomu-predmetu-geografiya-1.pdf); [методические рекомендации](https://edsoo.ru/mr-geografiya/2/) | Для картографического пункта нужна доступная ученику карта/схема именно нужной темы. |
| Биология | [Банк и методические рекомендации ЕДСОО](https://edsoo.ru/mr-biologiya/3/) | Проверять связь строения и функции/классификации, а не только память о термине. |
| Иностранный язык | [Методические рекомендации ЕДСОО](https://edsoo.ru/wp-content/uploads/2025/08/inostrannyj-yazyk.pdf) | Устная продукция и понимание аудио требуют соответствующего свидетельства; текстовый выбор ответа ограничен. |

Методическая опора на [IES: извлечение, интервалы и объясняющие вопросы](https://ies.ed.gov/ncee/wwc/PracticeGuide/1) и [EEF: оценивание исходных знаний в математике](https://educationendowmentfoundation.org.uk/education-evidence/guidance-reports/maths-ks-2-3) общая для планирования и обратной связи. Она не определяет российский школьный ключ. Для каждой новой темы в закрытом плане обязательны дата исследования, конкретный раздел программы, страницы семейного учебника, история ученика и происхождение каждого пункта.

### Шаблон записи для любого нового предмета

`предмет / класс / регион / период / подтверждённая тема / учебник семьи + издание и страницы / официальный документ + конкретный раздел / 2–3 образца работ с проверкой качества / матрица умений и форм ответа / ограничения / дата исследования`.
