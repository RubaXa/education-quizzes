# Короткая самопроверка после чтения

**Статус:** методическое основание для [ветки чистого чтения](../product/assessment-decision-graph.md#reading-only). Не является школьным критерием и не подтверждает буквально, что прочитана каждая строка.

В назначении «прочитать / познакомиться с текстом» без письменного результата родителю важно понять, уловил ли ребёнок основные идеи. [Руководство IES для 4–9 классов](https://ies.ed.gov/ncee/wwc/PracticeGuide/29) рекомендует давать возможность отвечать на вопросы по тексту, выделять его суть и отслеживать понимание. [Обзор EEF](https://educationendowmentfoundation.org.uk/education-evidence/teaching-learning-toolkit/reading-comprehension-strategies/) относит вопросы, уточнение непонятного, пересказ и вывод главной мысли к стратегиям понимания чтения. Отсюда следует **проектное решение Education**: короткий тест по назначенному тексту, а не вывод, что любую книгу можно проверить одними вариантами ответа.

Для обычного параграфа достаточно нескольких вопросов: главная мысль, важные понятия, одна причинная или смысловая связь и при необходимости простой перенос. Нужный объём зависит от текста; длинная контрольная к формуле «познакомиться» избыточна. Если в конце параграфа есть вопросы автора, они помогают выбрать содержание и формулировки; они не становятся обязательными пунктами МЭШ без назначения учителя. Нельзя заменять чтение тестом по случайному интернет-материалу с похожим названием.

Дополнительные вопросы из персональной траектории допускаются по общему [графу тестов](../product/assessment-decision-graph.md#contract), но порог выполнения читаемой темы должен допускать ошибки в этих вопросах. Подготовка к самостоятельной или контрольной — отдельный диагностический режим с более широким охватом и анализом пробелов. Проверка прочитанного не равна проверке выразительного чтения, устного выступления и школьной оценки.
