## Методический вывод для Education

Предложенный семьёй цикл «полный список → полный повтор → только ошибки до правильного написания» пригоден для диагностики и адресной тренировки. Дополнение по источникам — отдельная отложенная проверка всего списка без подсказок, предпочтительно в другой день. Точная задержка выбирается по сроку школьного диктанта и истории ребёнка, а не задаётся исследованием как обязательное число. Не следует бесконечно переписывать слово: после ошибки показать правильную форму и трудный фрагмент, затем закрыть образец и попросить вновь написать; если ошибок больше нет, остановить текущую тренировку.

Для диктанта по иностранному языку основной пункт — написание целевого слова по **однозначной подсказке** (произношение, точный перевод с контекстом или изображение). Узнавание из вариантов может быть разминкой, но не подтверждает правописание. Для русского — диктовка/контекст с открытым написанием. Прежде чем оценивать, сверить точный список учителя и допускаемые варианты; рукописная фотография с неоднозначными словами служит поводом для сверки, не готовым ключом.
