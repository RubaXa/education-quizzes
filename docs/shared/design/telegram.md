# Уведомления Education в Telegram

## Назначение

Прямой запрос18.10 и уточнение18.10: внедрить через Luna оформление, связанное с общей дизайн-системой; добавить шаблоны UI Kit и после просмотра реальных примеров сделать Telegram-сообщение компактным. Новый дизайн не меняет учебные факты или правила авторизации. Основание компактного digest — [решение 2026-10-18](../../decisions/telegram-compact-digest-2026-10-18.md).

<a id="компактная-сводка"></a>
## Визуальная система

Чистая общая digest-модель используется renderer и UI Kit; preview выводит её готовый текст без отдельной композиции. Сообщение — одна компактная шапка «ребёнок · предмет» и строки реальных изменений: короткий символ статуса, точное название задания или оценка, подпись статуса и только нужные дата/контекст. Повторяющиеся названия события, шапка Education, декоративные heading/divider/footer исключены. Событие review без точного задания и подтверждённого статуса не добавляется в сводку; пустое статусное сообщение не создаётся. Длинные имена и названия переносятся в пределах безопасной проекции; API длина не является целевой высотой сообщения. Новая часть содержит максимум6строк фактов и1200символов, следующие факты переходят в нумерованную часть без потери.

Общий словарь статусов содержит смысл, подпись, tone, Lucide name и Telegram fallback symbol; сайт использует существующие CSS токены, Telegram — нативные стили клиента. Произвольный CSS/точный фирменный hex в Telegram не обещается. Фото получено означает waiting, проверенное выполнение — complete; учебная ошибка и технический сбой различаются. Основное действие показывается только при доказанном безопасном контексте и только если формат доставки его поддерживает.

Для текущего семейного digest production использует обычное HTML `sendMessage` сообщение: нативный размер текста, одна шапка и строки, без rich heading, divider, footer и искусственных цветов. Rich Messages не являются требованием этого шаблона. Статус всегда выражен символом и короткой подписью; сайт по-прежнему использует semantic CSS tokens. Демонстрационный UI Kit показывает тот же production digest text на условных данных, помечает симуляцию и проверяет длинные строки/узкий экран; CSS страницы не обещает точный рендер мессенджера. Каталог сохраняет шаблоны upload, grade, homework, review, quiz, schedule, technical. Служебный демонстрационный пример явно подписан и не выдаётся за новую оценку ребёнка.

## Совместимость и безопасность

Durable outbox сохраняет неизменяемые части сообщения и их формат. Существующие v1/v2 части продолжают проходить общие receipt/retry/restart/membership/channel проверки; текущий compact digest сериализуется в HTML `sendMessage`. Неподтверждённые ссылки, raw source URL, disk path, токены, ответы и приватный payload не отображаются. Канонический маршрут приложения выбирает контекст, авторизация приложения отдельно проверяет родителя; preview не даёт доступа к чужой семье.

## Приёмка

Тесты общего словаря, digest, всех event templates, экранирования/инъекций, русских дат, длины/Unicode, неподдерживаемой схемы, v1 compatibility, частичных receipts и retry; UI Kit без семейных чтений и сетевой отправки. Браузерный скрипт проверяет 320/390/540px, три короткие строки и шапку (до200px на390/540, до240px на320), обычный размер шрифта, перенос длинных имён/названий и отсутствие сообщения при контекстном пробеле. Реальные примеры идут только в уже подтверждённый пользовательский чат с явной demo подписью и результатом Telegram API. UI Kit и runtime выпускаются отдельно; локальное изменение CSS не означает публикацию. Первая итерация и её реальные проверки описаны в [решении дизайн-системы](../../decisions/telegram-design-system-2026-10-18.md); компактный формат и текущий статус — в [решении digest](../../decisions/telegram-compact-digest-2026-10-18.md).

Основание возможностей: [Rich Messages](https://core.telegram.org/bots/features#rich-messages), [Bot API](https://core.telegram.org/bots/api#sendrichmessage), проверено18.10.2026. Наличие метода в документации отдельно от фактической доступности API/отображения клиента.
